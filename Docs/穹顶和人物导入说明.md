# 穹顶、God 和 Jesus：下载与拖入（UE 5.7）

资产位于 `Content/云/Dome_Panorama/`，包含两块穹顶模型，以及它们使用的材质实例、主材质和全景贴图。两块模型共用 `Enhanced/MI_Dome_Unified`，默认材质已绑定。

## 完整下载

本仓库使用 Git LFS。安装 Git LFS 后，在终端运行：

```powershell
git lfs install
git clone https://github.com/BBandeng/MR_Textility.git
cd MR_Textility
git lfs pull
```

已经克隆过仓库时，在仓库目录运行 `git pull`，再运行 `git lfs pull`。请等大文件下载完成后再打开 UE；`.uasset` 应为实际二进制资产，不能是只有几行文字的 LFS 指针。

## 放入自己的工程

使用 Unreal Engine 5.7。关闭目标工程，将下载得到的整个 `Content/云/Dome_Panorama` 文件夹复制到目标工程的同一路径，再打开工程。保留完整文件夹结构，材质与贴图引用才能正确对应。

在内容浏览器打开 `云/Dome_Panorama`，把 `SM_Dome_PanoramaBand` 和 `SM_Dome_UpperCap` 拖入自己的关卡。两块模型会自带材质。

两块模型使用相同变换：位置 `X=0, Y=0, Z=-2200`（厘米）、旋转 `0, 0, 0`、缩放 `1, 1, 1`。这样可拼成当前场景中的完整穹顶。

## 移动、旋转与调色

材质使用世界坐标计算贴图方向。移动整个穹顶时，要同时移动两块模型，并在 `Enhanced/MI_Dome_Unified` 中启用向量参数 `DomeCenter`，把 `R/G/B` 分别设为新的中心 `X/Y/Z`；`A` 不参与计算。初始值为 `(0, 0, -2200)`。保持两块模型同中心，可避免上下贴图错位。

需要改变全景的水平方向时，调整 `RotateU`：`0.25` 相当于四分之一圈，`1` 为一整圈。使用 `Brightness` 调整亮度。若同一关卡要摆放多个不同中心的穹顶，分别复制材质实例，为每个穹顶设置各自的 `DomeCenter`，并将该实例分配给对应的两块模型。


## God 与 Jesus

当前导入的原生资产分别位于 `Content/God/` 和 `Content/Jesus/`，各自包含模型、材质与全部贴图。

在内容浏览器中打开 `God/StaticMeshes` 或 `Jesus/StaticMeshes`，选择需要的模型部件并拖入关卡。God 含 6 块网格，Jesus 含 10 块网格，各部件保留原始相对位置和默认材质。需要完整人物时，将同一人物的全部部件一起拖入。

把人物放进其他工程时，关闭目标工程，将完整 `Content/God` 和 `Content/Jesus` 文件夹复制到目标工程的相同路径。保留文件夹结构；不要只复制模型文件。也可以在 UE 内容浏览器中选择人物全部模型，使用“资产操作 → 迁移”，选择目标工程的 `Content` 文件夹，让 UE 一起迁移材质与贴图。

人物材质使用 UE 内置 Interchange 材质资源。目标工程应使用 UE 5.7 并启用内置 Interchange 插件；无须重新导入 GLB。
